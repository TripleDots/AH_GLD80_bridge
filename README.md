Allen & Heath GLD 80 bridge

A custom bridge to bring more features to MIDI with MCU.
This makes the desk a bit more studio ready.
Keep in mind that the faders are only 7 bit (127 steps). So you won't be doing precize mixes and/or automations with it.
But it works great for setting up a mix fast for (virtual) instruments when tracking.

For the deepest integration, make sure that you install the official Allen and Heath GLD Editor and Allen and Heath MIDI Control
The software will work mostly without it, but to get the most out of it, this app will tap into the editor.
You don't have to have them open. The software does it all in the background.
Sadly, this means that you can only achieve the deepest integration on Windows and MacOS.

For REAPER users, it comes with a companion script.
This allows a deeper integration, like being able to color the tracks based on DAW track colors.
There aren't much DAWs that allow you to do that. So for other DAWs, you either have to color it on the desk or leave it as default.

I have only tested it on Windows 11 with REAPER and Davinci Resolve.
It should also work on MacoOS and Linux including the installers.
For Windows users, you can use either the integrated MIDI 2.0 or LoopMidi to create midi ports.
MacOS has it built in, like most Linux distros.

If you want to vibe code any changes, just upload the .zip to ChatGPT. You'll need a Plus account or else you'll have to constantly add the new code yourself to the right file.
